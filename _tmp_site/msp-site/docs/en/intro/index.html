Introduction

Two nodes, five minutes: one offers a tool, the other discovers it and calls it.

1. Install​

pip install --pre msp-py        # pre-release on PyPI for now
# or from source:
pip install -e .

pip install -e . is an editable install — source edits take effect immediately (use a virtual environment).

2. The side that offers a capability​

Save as weather.py:

from msp import MSPNode, Preset

node = MSPNode("weather", preset=Preset.LOCAL_TOOL)


@node.tool("get_weather", "Look up the weather")
def get_weather(location: str, days: int = 3) -> dict:
    return {"location": location, "days": days, "temp_c": 21}


if __name__ == "__main__":
    node.start()
    input("press enter to quit\n")

@node.tool does more than register a function: it declares the tool in the node's capability manifest, so a neighbour sees it during the handshake.

3. The side that uses it​

Save as agent.py, run one in each terminal:

from msp import MSPNode, Preset

node = MSPNode("agent", preset=Preset.FULL_PEER)
node.start()

print("neighbours:", node.neighbors())

result = node.call("weather", "get_weather", {"location": "Hangzhou"})
print("result:", result.unwrap() if not result.is_error else result.error)

Within two seconds you should see neighbours: ['weather'] and a JSON payload.

4. How they found each other​

Both write a "I am here" declaration into the same directory and poll that directory:

~/.msp/nodes/weather.json     ← the node id is the file name
~/.msp/nodes/agent.json

timestamp is a lease, not metadata:

ParameterValueMeaning
renew interval10 sthe announcer rewrites timestamp every 10 s
stale threshold30 snow - timestamp > 30s means expired, i.e. "node is dead"
poll fallback30 sfull directory scan when the event channel misses something

So a crashed node takes at most 60 s to disappear: up to 30 s before it is judged stale, plus at most one more 30 s poll cycle.

Discovery has two legs: a filesystem event channel (realtime) and a 30 s poll fallback for when events are missed. Discovery and announcement are orthogonal layers — scan without announcing (observe only), or announce without scanning (be listed without dialling out).

Pass nodes_dir= to use another directory. Two nodes using different directories simply cannot see each other.
