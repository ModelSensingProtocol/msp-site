# Example nodes

Four nodes that run straight away, covering a few of the main threads of MSP. The code on
each page is **word-for-word identical** to `static/examples/*.py` (generated by a
script, so it cannot drift), and every one of them has been run. In this English edition
only the comments and the printed messages are translated; every statement is unchanged:

```bash
cd docs-site
PYTHONPATH=../src python tools/check_examples.py
```

| Example | What it demonstrates | Key API |
|---|---|---|
| [Weather node](weather.md) | Smallest capability provider | `@node.tool` |
| [Downloader node](downloader.md) | Long task + progress push + check back | `start_task` / `get_task` / `publish` |
| [Editor node](editor.md) | Subscribe + **direct app-to-app link** | `@node.on("download.*")` |
| [Observer](probe.md) | Only watches, does not speak (discovery and announcement are orthogonal) | `Preset.OBSERVER` |

## Running them together

Open three terminals (all in the root of the `ModelSensingProtocol` repository, with `export PYTHONPATH=src` run first):

```bash
python examples/downloader.py     # terminal 1: offers start_task / get_task
python examples/editor.py         # terminal 2: subscribes to download.*
python examples/weather.py        # terminal 3: plain tool node, optional
```

Then let any node (or agent) make the call:

```python
from msp import MSPNode, Preset

node = MSPNode("driver", preset=Preset.FULL_PEER)
node.start()
print(node.call("downloader", "start_task", {"url": "https://example.com/x", "size_mb": 5}).unwrap())
```

A few seconds later, terminal 2 prints `[editor] got download.completed: {...}` — that path **does not go through the model**.

## Isolated demo environment

Every example reads the environment variable `MSP_NODES_DIR` (default `~/.msp/nodes`):

```bash
MSP_NODES_DIR=/tmp/msp-demo python examples/weather.py
```

That way the demo nodes do not share a discovery directory with your real nodes.

## After changing the examples

`/docs/` shows the **2026-10-10 version snapshot**, so a change only reaches the default path once it has been synced in:

```bash
cd docs-site
rm -rf versioned_docs versioned_sidebars && echo '[]' > versions.json
# temporarily comment out lastVersion/versions in docusaurus.config.js, then:
./node_modules/.bin/docusaurus docs:version 2026-10-10
# then restore those two lines
```

If you only change example code, do not forget the same copy in `versioned_docs/`.

## These examples are not "looks like it runs"

`tools/check_examples.py` does three real things:

1. Starts `weather.py`, calls `get_weather` from a client, and asserts on the returned fields;
2. Starts `downloader.py` + `editor.py`, triggers a task, and asserts that the subscriber **really** received the completion signal;
3. Starts `probe.py` and asserts that it can see the others.

Run it every time you change an example or `tools/check_examples.py`; only when all three come out green does it count.
