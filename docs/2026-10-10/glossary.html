术语表

按在协议里的层次从低到高排。

术语英文一句话在哪
信号signal一条带路径的 JSON 报文；8 个顶层字段恒定，未知字段进 extrascore/signal.py
分帧framing4 字节大端长度前缀 + UTF-8 JSONprotocol/framing.py
清单manifest节点宣告自己的工具、信号、能力、模式core/manifest.py
握手handshakeHELLO（带 manifest）→ ACK（带回对方 manifest）protocol/protocol.py
去重仲裁dedup / canonical direction两个节点同时拨号时，按 node_id 字典序保留一个方向同上
工具tool请求-应答的能力，有名字、描述、输入 schemacore/node.py
调用call调对端工具，返回 ToolResult；失败不抛异常同上
广播publish / broadcast发一条信号给所有已订阅的对端；发完即忘、无留存同上
订阅subscription用路径模式（* / **）注册本地回调protocol/matcher.py
发现discovery扫描共享目录，把新节点变成可拨的对端discovery/
宣告presence往共享目录写自己的声明文件并续租presence/
租约lease声明的有效期：30 秒没有续租即视为失联同上
预置preset一组能力的打包：发现、宣告、传输、模式、连接策略core/preset.py
连接策略connect policyeager（发现即连）/ lazy（用到才连）同上
稳定settle等"这次启动触发的建连"落地，只等不发起core/node.py
模式pattern可插拔的交互形状：request-reply / publish-subscribe / multi-round / taskpatterns/
任务taskmulti-round 的一种：有队列、有状态、可回查patterns/task.py
授权grant按 (对端, 路径模式) 决定能不能发/收/调；跨机默认不信任protocol/protocol.py
本机对端local peer回环 TCP 或 UDS 连接的对端，默认视为本机同上
指标metrics连接 / 信号 / 工具 / 任务线程各维度的计数core/node.py
适配层adapter把 MCP server 包成一个 MSP 节点的那一层mcp/
